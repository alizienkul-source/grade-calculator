# grade-calculator-
Short description: what the program does and who it is for.
## Requirements
- The program shall allow the teacher to enter a student's name.
- The program shall accept exactly five whole-number scores for each student.
- The program shall check that every score is between 0 and 100 and ask again if the score is invalid.
- The program shall calculate the student's average score and assign a grade (A, B, C, or F).
- The program shall allow the teacher to enter multiple students, finish by typing "end", and display the total number of students and the class average.
## Grading scale
| Grade | Average |
|-------|---------|
| A | 90 - 100 |
| ... | ... |
